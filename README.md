# Money Talks Georgia

A luxury landing page for Money Talks Georgia - handcrafted decorative frames featuring real money, luxury cars, and premium designs.

## Features

- Modern, responsive design with dark/light theme toggle
- Bilingual support (English / Georgian)
- Smooth animations with Framer Motion
- Mobile-first responsive layout

## Tech Stack

- React 19
- Vite
- Tailwind CSS 4
- Framer Motion
- react-i18next

## Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build

```bash
npm run build
```

## Project Structure

```
src/
├── components/       # React components
├── context/          # Theme context
├── i18n/             # Translations (en.json, ka.json)
├── lib/              # Utility functions
├── App.jsx           # Main app component
├── main.jsx          # Entry point
└── index.css         # Global styles
```
